# Expedition OMEGA Deck Progression

- Expedition Mode no longer waits for the 03:00 / 06:00 / 09:00 OMEGA timers.
- Decks 1, 2, and 3 each contain exactly one OMEGA Core opportunity.
- The OMEGA hunt activates after the player secures the first expedition objective on that deck.
- Once that deck's Core is collected, no second Core can spawn on the same deck.
- Decks 4 and 5 do not schedule additional OMEGA Cores.
- If an active OMEGA opportunity remains unresolved when the Broodmother dies, the boss may release that deck's Core.
- If the player extracts without collecting a deck's Core, that opportunity is missed; it is not converted into a later time-based spawn.
- Classic non-expedition Survival Mode retains the original time-based OMEGA scheduling.
