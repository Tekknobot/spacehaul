# Omega Carrier + Directional Signal Patch

- Omega Core acquisition is now an explicit hunt event once the active chassis reaches primary Tier III and the run has passed the Omega timing gate.
- The director spawns exactly one marked **Omega Carrier** rather than allowing any ordinary elite to release the Core.
- Omega Carriers have extra health, a magenta/white vertical signal, isometric ground ring, orbiting pixel lines, phase particles, and a magenta elite health bar.
- A HUD edge arrow labeled **OMEGA** points toward an off-screen carrier. When the carrier dies, the same guidance continues to the stationary dropped Core as **OMEGA CORE**.
- Guidance disappears when the carrier/Core is already visible on-screen.
- Deck regeneration clears the old spatial target but preserves the opportunity: if the player is still eligible, a replacement carrier is queued after the new deck's grace period.
- Ordinary elites no longer drop Omega Cores. The designated carrier does. The Broodmother remains a fallback Omega source if the player is eligible and no carrier/Core is active.
- The one-Legendary-per-run rule remains unchanged.
