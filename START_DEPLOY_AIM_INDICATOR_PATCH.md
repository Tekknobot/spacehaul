# START Deploy + Aim Indicator Patch

- Controller deploy in the chassis showroom now uses START instead of A.
- Keyboard deploy remains Enter; mouse deploy remains the DEPLOY button.
- A remains dedicated to dash during gameplay.
- The player marker arrow is now a directional pointer with a clear forward tip and stem.
- The pointer rotates continuously to the live mouse/right-stick aim vector.
- The pointer follows live player aim continuously, even while an attack animation is resolving.
- Active-device tracking prevents a centered controller stick from snapping the pointer toward a stale mouse cursor.
