# SpaceMECHA — Omega LMB Toggle + M3 Orbital Rain Saturation

## Omega primary mode
- Mouse wheel up or down toggles an acquired Legendary primary between the normal Tier III LMB and the selected Omega mutation.
- A newly chosen Omega starts active.
- HUD shows `OMEGA <name>` when active and `OMEGA STBY` while the standard LMB is selected.
- A short banner confirms `LMB OMEGA` / `LMB STANDARD`.
- RMB never inherits the primary Omega mutation.

## M3 COMET / Orbital Rain
- Base Orbital Rain retains its perimeter-ring identity.
- Tier I uses staggered inner/outer strike bands.
- Tier II uses area-filling sunflower placement.
- Tier III SATURATION fills the full isometric disk, includes a center strike, concentric field pulses, and one full-radius gameplay hit so enemies between impact sprites are not missed.
