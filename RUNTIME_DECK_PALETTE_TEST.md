# Runtime Deck Palette Test

- Press **P** during a run to immediately trigger the normal cinematic deck transfer.
- Repeated presses cycle Deck 1 -> 2 -> 3 -> 4 -> 5 -> 1.
- The regular four-minute deck timer restarts from the cheat-selected deck.
- Every procedural regeneration now rebuilds and explicitly reapplies a fresh ShaderMaterial at runtime.
- The top HUD shows the active palette name next to the deck number.
- Deck 1 remains the authored STEEL colors; later decks use strong palette grading while retaining source brightness/contrast.
