# SpaceMECHA — Omega Roster Expansion

This pass expands the tested ATLAS Omega loop to all ten playable chassis.

## Universal acquisition
- Omega Cores can now be collected by every mecha.
- A Core can be held before the signature primary reaches Tier III.
- Tier III on the primary changes the HUD to `OMEGA SEEK`.
- A held Core opens a chassis-specific three-choice Omega screen as soon as the primary reaches Tier III.
- One Legendary mutation is allowed per run; once chosen, further Omega drops are suppressed.

## Signature primary mutations
- M1 ATLAS / Plasma Cleaver: Omega Edge, Atlas Crown, World Breaker.
- M2 PANTHER / Vector Harpoons: Predator Grid, Apex Reel, Kill Lattice.
- M3 COMET / Comet Mortar: Meteor Shower, Cluster Sun, Comet Corridor.
- R1 PRISM / Prism Lance: Prism Wall, Kaleidoscope, Refraction Engine.
- R2 BREACHER / Breach Cannon: Rail Annihilator, Breach Trident, Fault Engine.
- R3 HUNTER / Hunter Missiles: Cerberus Protocol, Orbital Pack, Recursive Warhead.
- R4 CASCADE / Arc Cascade: Tesla Storm, Arc Web, Neural Overload.
- S1 SOLARIS / Photon Rake: Sunfire Grid, Solar Cross, Corona Breaker.
- S2 PHANTOM / Gravity Well: Black Star, Orbital Prison, Event Horizon.
- S3 SPIDER / Phase Needles: Phase Fusillade, Web Crown, Ghost Swarm.

All new mutations reuse the project's current hard-pixel line rendering, additive bloom, isometric rings, explosions and particle emitters. No new art assets are required for this pass.
